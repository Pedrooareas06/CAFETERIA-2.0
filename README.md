# Cafeteria Aroma 2.0 ☕

Aplicação web moderna para cafeteria, com menu dinâmico, carrinho de compras e chatbot com IA integrado.

## 🚀 Tecnologias

- **Next.js (App Router)** + **TypeScript**
- **React 18**
- **Tailwind CSS**
- **shadcn/ui**
- **OpenAI API** (Chatbot IA)
- **React Hook Form** + **Zod**

## 📦 Instalação

```bash
# Clone o repositório
git clone <URL_DO_REPOSITORIO>
cd cafeteria-aroma-2.0

# Instale as dependências
yarn install

# Configure variáveis de ambiente
cp .env.example .env.local
# Adicione sua OPENAI_API_KEY no .env.local

# Inicie o servidor
yarn dev
