# Café Raízes 2.0 🌱☕

Aplicação web moderna e responsiva para cafeteria artesanal premium. Apresenta vitrine de produtos, cardápio interativo, sistema de pedidos via WhatsApp e assistente de IA para atender clientes.

**Este é um projeto 100% frontend** - sem banco de dados, sem API backend persistente. Ideal para portfólio profissional e demonstração de skills em desenvolvimento web.

## 🎯 Características

- ✅ Design moderno e responsivo (mobile-first)
- ✅ Cardápio dinâmico com filtros de categoria
- ✅ Integração WhatsApp para pedidos
- ✅ Assistente IA (simulado) para atendimento
- ✅ Animações smooth com scroll
- ✅ SEO otimizado (Open Graph, Twitter Cards)
- ✅ Acessibilidade WCAG 2.1 (labels, aria-labels, focus visível)
- ✅ Performance otimizada (next/image, React.memo)

## 🚀 Tecnologias

- **Next.js 14+** (App Router) + **TypeScript**
- **React 18**
- **Tailwind CSS** + **PostCSS**
- **shadcn/ui** (Radix UI + Tailwind)
- **Lucide React** (ícones)
- **React Hook Form** + **Zod** (validação)
- **Vercel AI SDK** (para integração com IA)

## 📦 Instalação e Setup

### Pré-requisitos
- Node.js 18+ ou superior
- Yarn (recomendado) ou npm

### Passos

```bash
# Clone o repositório
git clone <URL_DO_REPOSITORIO>
cd cateria-2.0

# Instale as dependências
yarn install

# Inicie o servidor de desenvolvimento
yarn dev
```

Acesse `http://localhost:3000` no navegador.
